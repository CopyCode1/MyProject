# GT02 项目文档索引

本工程的项目说明文档统一使用中文文件名。`SKILL.md` 是工具要求的固定入口，保留原名；
代码、Kconfig、CMake、设备树和构建目录也保持各自约定的命名。

## 一、先读哪些文档？

1. 想编译、烧录、调试当前工程：读 [NCS开发说明](../../NCS开发说明.md)。
2. 想理解整个产品怎样从零设计：读 [GT02产品工程设计指南](../GT02产品工程设计指南.md)。
3. 想理解工程目录、组件和依赖：读 [软件架构与组件规划](../product/05_软件架构与组件规划.md)。
4. 想先直观看到AT、URC、二进制和多连接怎样工作：用浏览器打开 [4G通信设计交互实验室](4G通信设计交互实验室.html)，再按需查阅 [完整教程](4G通信从AT到多连接的心智模型与设计取舍教程.md)。
5. 想查看当前实际代码从哪里重新开始：读 [4G重建第一步：硬件适配](../product/11_4G重建第一步_硬件适配.md)。
6. 想开始实现Lierda四条TCP连接：结合教程，读 [4G多连接分层架构设计](4G多连接分层架构设计.md)，再核对硬件和型号。

## 五、怎样理解文档状态？

- “设计方案”说明准备怎样实现，不等于代码已经存在。
- “构建通过”不等于实板功能、功耗和异常恢复已经验证。
- 产品基线和验证记录可能描述不同阶段，阅读时应结合日期、配置和对应固件。
- 本次更名保留原有历史正文，不把过去的进度描述重写为当前验收结论。
- 查找旧英文文件名时，可从本索引按主题定位；不再保留两份同内容文档，避免后续维护分叉。
